# Mission: React JS Job Preparation

## Why
I want to become interview-ready for frontend React roles. I can already build components and simple apps, but I want stronger JavaScript and React fundamentals so I can explain my decisions, debug common problems, and implement realistic tasks confidently in interviews.

## Success looks like
- Explain the JavaScript concepts React relies on—arrays, `map`/`filter`, objects, destructuring, spread, closures, and asynchronous code—with small examples.
- Build small React interfaces from data and handle props, state, forms, effects, loading, errors, and accessibility deliberately.
- Explain rendering, keys, state structure, effects, testing, and performance trade-offs in concise interview answers.
- Solve common React interview exercises and justify the implementation rather than recalling a tutorial mechanically.
- Build and explain a small frontend project that demonstrates the fundamentals.

## Constraints
- Lessons should be short, interactive, and flexible; roughly three hours per week is available, but there is no hard study-time limit.
- The initial target is interview readiness in about one month, while allowing the curriculum to continue at the user's pace.
- Start at interview-ready fundamentals rather than installation walkthroughs.
- Focus on frontend React, progressively including JavaScript/TypeScript, browser behavior, testing, and practical UI work.

## Out of scope
- Employer-specific preparation until a job description is available.
- Deep backend, Next.js, or state-library material before the React and JavaScript mental models are solid.
- Re-teaching basic HTML/CSS unless it becomes a blocker for a React task.
