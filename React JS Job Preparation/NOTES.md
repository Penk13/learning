# Teaching notes

- The learner can build React components and simple apps.
- The target is a frontend React developer role.
- The learner identified JavaScript fundamentals and modern syntax as the weakest/highest-priority area.
- The initial interview-ready target is about one month, but study time is flexible; approximately three hours per week is a baseline, not a hard constraint.
- Prefer short, interactive lessons with retrieval practice over passive tutorial coverage.
