React list rendering

The compact mental model behind turning JavaScript data into stable, readable JSX lists.

The pipeline
Array of data
→
filter() if needed
→
map() to JSX
→
Stable key
→
Render the array

map()

Calls a callback for each item and returns a new array containing each callback result.

const names = ["Ada", "Grace"];
const items = names.map(name => <li>{name}</li>);

Destructuring

Unpacks object properties into local bindings, including directly in a callback parameter.

people.map(({ id, name }) => (
  <li key={id}>{name}</li>
));

Keys

A key is stable identity for an item among its siblings. Prefer a persistent data ID.

Avoid array indexes when order can change; never generate keys with Math.random().

Immutability

map(), filter(), slice(), and spread create new arrays. push(), pop(), and splice() mutate.

For arrays in React state, create a new array before setting the next state.

Interview distinction. key is used by React to track list items; it is not passed to the component as a normal prop. If the component needs the ID, pass a separate prop such as itemId={id}.
Thirty-second answer
“I keep the source data as an array, optionally filter it, then use map() to transform each record into JSX. Each mapped element gets a stable key from the data so React can match items when the collection changes. I avoid mutating arrays, especially arrays held in state, and use non-mutating methods or spread to produce the next array.”
