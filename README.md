## Structure

Each course follows the same layout:

- `MISSION.md` — goal and scope
- `lessons/` — HTML lessons (open in browser)
- `reference/` — cheatsheets
- `learning-records/` — progress log
- `NOTES.md`, `RESOURCES.md` — notes and external links
