List rendering (0001)

Array of data
→
filter() if needed
→
map() to JSX
→
Stable key
→
Render the array

map()

Calls a callback for each item and returns a new array of the results.

const items = names.map(name => <li>{name}</li>);

Destructuring

Unpacks properties into local bindings, including in a callback parameter.

people.map(({ id, name }) => (
  <li key={id}>{name}</li>
));

Keys

Stable identity for an item among its siblings. Prefer a persistent data ID.

Avoid indexes when order can change; never use Math.random().

Immutability

map(), filter(), slice() and spread create new arrays. push(), pop() and splice() mutate.

Object/array spread is a shallow copy: nested objects are still shared.

Arrow bodies

x => (<li/>) returns implicitly; x => { … } needs return.

Interview distinction. key is used by React to track list items; it is not passed to the component as a normal prop. If the component needs the ID, pass a separate prop such as itemId={id}.
“I keep the source data as an array, optionally filter it, then map() each record into JSX. Each element gets a stable key from the data so React can match items when the collection changes. I avoid mutating arrays, especially in state, and use non-mutating methods or spread to produce the next array.”

Source: React — Rendering Lists.
