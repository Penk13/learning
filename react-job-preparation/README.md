# React JS Job Preparation

A flexible, interview-oriented learning workspace for frontend React roles.

## Start here

1. Read [[MISSION]] to keep the learning path grounded in the job goal.
2. Complete the lessons in `lessons/` in numerical order.
3. Use `reference/` for quick review after a lesson.
4. Check [[RESOURCES]] when you want the primary documentation behind a concept.
5. Ask the teacher follow-up questions whenever an explanation or exercise feels unclear.

## Learning loop

Each lesson is designed to fit in a short sitting:

1. Learn one mental model.
2. Retrieve it before looking at the answer.
3. Use the interactive checks for immediate feedback.
4. Apply the idea to a small React-flavored example.

The first lesson connects JavaScript array transformation and object destructuring to React list rendering—the first step toward explaining common frontend interview code clearly.
