# React JS Job Preparation Resources

## Knowledge

- [React Learn — Quick Start](https://react.dev/learn)
  Official React overview of components, JSX, displaying data, conditions, lists, events, and state. Use as the main curriculum map and version-current reference.
- [React Learn — Describing the UI](https://react.dev/learn/describing-the-ui)
  Official explanation of components, JSX, JavaScript expressions in JSX, props, conditional rendering, lists, purity, and the UI tree. Use for React's core rendering vocabulary.
- [React Learn — Rendering Lists](https://react.dev/learn/rendering-lists)
  Official guide to using `filter()` and `map()` to produce JSX, and to choosing stable `key` values. Use for list-rendering exercises and interview explanations.
- [React Learn — Updating Arrays in State](https://react.dev/learn/updating-arrays-in-state)
  Official guide to treating arrays in React state as read-only and choosing non-mutating operations such as `map`, `filter`, `slice`, and spread. Use when state updates are introduced.
- [MDN — `Array.prototype.map()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/map)
  JavaScript reference for `map`: callback behavior, the new returned array, and common hazards. Use when a React example depends on array transformation.
- [MDN — Destructuring](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment)
  JavaScript reference for unpacking array values and object properties into bindings. Use for function parameters and readable component code.
- [MDN — Spread syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax)
  JavaScript reference for expanding arrays/iterables and copying or composing object literals. Use when explaining immutable updates and the limits of shallow copying.
