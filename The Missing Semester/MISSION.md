# Mission: The Missing Semester for Daily Development

## Why

I want to become more effective in my current .NET/React and Django development work by building practical fluency with the tools around the code: the shell, development environment, debugging and profiling, Git, packaging and shipping, AI-assisted development, and code quality. The goal is to spend less time fighting tools and to make more reliable, explainable engineering decisions.

## Success looks like

- Navigate, inspect, transform, and automate project files confidently from the shell.
- Set up a productive development environment and choose appropriate tools for a task.
- Reproduce bugs, investigate them systematically, and use profiling evidence rather than guesses.
- Use Git beyond basic commits: inspect history, isolate changes, recover safely, and collaborate clearly.
- Package and ship small applications or services with an understandable, repeatable workflow.
- Use AI coding agents with clear task boundaries, verification, and awareness of their failure modes.
- Apply practical code-quality habits—tests, automation, review, and maintainability—to .NET/React and Django work.
- Explain the purpose and trade-offs of these workflows in my own words, not only follow a tutorial.

## Constraints

- Lessons should be short and flexible: about 15–20 minutes, a few times per week.
- Begin from first principles because most topics are familiar only at a basic level.
- Practice should use safe, disposable WSL sandbox projects rather than work repositories.
- Examples should connect back to real .NET/React and Django development where useful.
- Use retrieval practice and immediate feedback instead of passive reading alone.

## Out of scope

- Replacing framework-specific .NET, React, or Django documentation with this course.
- Experimenting with work credentials, confidential repositories, or production systems.
- Exhaustively learning Linux administration or every tool in the ecosystem.
- Optimizing for one employer, interview, or job description unless the mission is revised later.
