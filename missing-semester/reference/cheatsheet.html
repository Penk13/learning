Shell Cheat Sheet

Topics 1–2 compressed: commands, streams, environment, scripts, signals, jobs, SSH, tmux, dotfiles.

Two models

  • Command = program + arguments. The shell splits the line, finds the program on $PATH, runs it; stdout flows to the terminal or through a pipe.
  • Children get a copy, changes never flow back. A child gets args + exported env + working directory and returns only an exit status. Hence: cd is a builtin, .bashrc/activate must be sourced, CI fails on non-zero exit.

Finding programs and help

echo $PATH            # ':'-separated dirs, searched in order
which date            # which file runs for 'date' ($PATH only)
type cd ls mkcd       # builtin / alias / function / file
man date; date --help; tldr date
pwd; cd ~ / .. -      # home / parent / previous dir
ls -la                # -l: type + permissions; -a: show dotfiles

Streams, pipes, exit status

cmd > f   cmd >> f     # stdout → file (overwrite / append)
cmd < f               # stdin ← file
cmd 2> err.txt        # stderr → file
cmd > all.txt 2>&1    # both → same file
cmd 2> /dev/null      # discard errors
a | b                 # stdout of a → stdin of b
cmd | tee log.txt     # show AND save
echo $?               # 0 = success
a && b   a || b   a ; b   # on success / on failure / always

Quoting, globs, substitution

'$PATH'  "$PATH"  My\ Photos   # literal / expands / escape one char
*.txt  file?.txt  {a,b,c}.txt  # shell expands before the program runs
today=$(date +%F)              # command substitution
"$var"                         # always quote expansions

Environment variables

foo=bar               # shell variable (this shell only)
export FOO=bar        # environment variable (copied to children)
FOO=bar cmd           # one-shot: only this child gets it
unset FOO; printenv   # remove / list exported vars
ASPNETCORE_ENVIRONMENT=Staging dotnet run
DJANGO_SETTINGS_MODULE=config.settings.test python manage.py test

Scripts

#!/usr/bin/env bash
set -euo pipefail     # stop on error / unset var / failed pipe part
"$0" "$1" "$@" "$#"   # name / first arg / all args / count
${1:-dev}             # $1, or "dev" if missing
exit 1                # status handed back
chmod +x s.sh; ./s.sh # run in a child (cd/export lost)
source s.sh  # or . s.sh: run in THIS shell (cd/export kept)
for i in $(seq 1 3); do echo "$i"; done
if [ -f "$1" ]; then echo exists; fi

Lint with shellcheck. Past ~100 lines, prefer Python.

Signals

SIGINTCtrl-C · catchable
SIGQUITCtrl-\ · rarely caught
SIGTERMkill PID · polite, allows cleanup
SIGKILLkill -9 PID · uncatchable, last resort
SIGTSTPCtrl-Z · pause
SIGHUPterminal closed · default: die
pgrep -lf name; pkill -f "pattern"; kill -l
docker stop           # SIGTERM → 10 s grace → SIGKILL
exec dotnet App.dll   # last line of an entrypoint script: app gets signals

Jobs and cleanup

cmd &                 # background;  $! = its PID
Ctrl-Z; bg            # forgot &: suspend, resume in background
jobs; fg %1; kill %2  # list / foreground / signal by job number
nohup cmd &           # ignore SIGHUP (output → nohup.out)
disown                # running job: shell won't send SIGHUP
wait; wait $!         # wait for own children
kill -0 PID           # exists? (sends nothing)
trap cleanup EXIT     # runs on any exit except SIGKILL

SSH

ssh vm ls | wc -l              # ls remote, wc local
ssh vm 'ls | wc -l'            # both remote
ssh-keygen -a 100 -t ed25519   # id_ed25519 = PRIVATE, .pub = public
ssh-copy-id -i ~/.ssh/id_ed25519 vm
ssh -L 9999:localhost:8888 vm  # laptop :9999 → vm's localhost:8888
scp f vm:/tmp/
rsync -av --partial dist/ vm:/srv/app/   # dist/ = contents, dist = folder

# ~/.ssh/config
Host vm
    User alice
    HostName 172.16.174.141
    IdentityFile ~/.ssh/id_ed25519

tmux (prefix Ctrl-b)

tmux new -s NAME; tmux ls; tmux a [-t NAME]; tmux kill-session -t NAME
<C-b> d               # detach (keeps running)
<C-b> c / n / p / 0-9 / , / w   # window: new / next / prev / jump / rename / list
<C-b> " / %           # split top-bottom / left-right
<C-b> arrow / z / [   # move pane / zoom / scrollback (q leaves)

Session → window → pane. The shell's parent is the tmux server, so SSH drops don't send it SIGHUP.

Dotfiles

export PATH="$PATH:$HOME/.dotnet/tools"   # append, never replace
alias gs="git status"; \ls; unalias gs     # define / bypass / remove
mkcd() { mkdir -p "$1" && cd "$1"; }      # function: args + runs in this shell
source ~/.bashrc                           # apply edits to an open shell
[ -f ~/.bashrc.local ] && source ~/.bashrc.local   # secrets, uncommitted
ln -sf ~/dotfiles/bashrc ~/.bashrc         # dotfiles repo + symlinks
Ctrl-R                                     # search history
curl -fsSL URL -o install.sh; less install.sh; bash install.sh   # not curl | bash

Everyday text tools

sort · uniq -csort lines · count consecutive duplicates
head · tailfirst · last lines
grep pattern filematching lines (regex)
sed -i 's/a/b/g' filereplace in place
find . -name "*.py"find files
