Commands, Arguments and PATH

A command is a program plus arguments; the shell's job is to split your line and find that program.

The model

The shell splits your line into words. The first word names a program, the rest are its arguments. The shell finds the program, runs it, and the program's output flows to the terminal.

The terminal is the window. The shell (on WSL/Linux usually bash; check with echo $SHELL) is the program inside it that interprets your commands.

Reading the prompt

missing:~$ date
Fri 10 Jan 2020 11:49:31 AM EST
missing:~$ echo hello
hello

missing:~$ shows the machine and the current working directory (~ = home). $ means a normal user, not root. Words are split on whitespace, so an argument with spaces must be quoted ("My Photos") or escaped (My\ Photos).

How the shell finds programs

$ echo $PATH
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
$ which echo
/bin/echo

$PATH is a :-separated list of directories, searched in order. The first executable file with the right name wins; which shows which file that is. That is why dotnet, npm and python work from any folder: they live in a $PATH directory.

Builtins: why which cd prints nothing

Some commands are not files at all but builtins, implemented inside the shell. cd must be one: a separate cd program would run as a child process, change its own directory, exit, and leave your shell where it was. A child can never change its parent's working directory.

$ which cd        # nothing: which only searches $PATH files
$ type cd
cd is a shell builtin
$ type ls
ls is aliased to `ls --color=auto'

Use type instead of which when you want the full truth: it reports builtins, aliases, functions and files.

Help is local

  • man date: the manual page (space to page, q to quit).
  • date --help: most programs print a short usage summary.
  • tldr date (install it): example-first help.
  • ls -l: one line per file; the first 10 characters are type and permissions (-rw-r--r-- = regular file, owner reads/writes, others read). man ls decodes the rest.

Try it

  1. echo $PATH, then which python3 and type cd.
  2. ls -l /: which lines are directories (first character d)?

Check yourself

How does bash find the program to run for a command like date?

$PATH is a :-separated list of directories. The shell tries each in order; which date shows the winner.

In bash, why does which cd print nothing, and what command shows what cd really is?

cd is a shell builtin, not a file on $PATH, and which only searches $PATH. It has to be a builtin because a child process cannot change its parent's working directory. type cd reports "cd is a shell builtin".

In a shell command line such as cp "My Photos" backup, what are the program and the arguments, and why are the quotes needed?

The shell splits the line on whitespace: cp is the program, My Photos and backup are its two arguments. Without quotes, My and Photos would become two separate arguments.
