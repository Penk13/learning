# The Missing Semester Resources

## Knowledge

- [The Missing Semester — official 2026 course index](https://missing.csail.mit.edu/2026/)
  The primary roadmap and source for the nine-lecture sequence in this project. Use it to anchor every lesson and follow the lecture-specific exercises.
- [Course source repository](https://github.com/missing-semester/missing-semester)
  The official source for the course website, notes, exercises, and supporting material. Use it when a lesson needs the original exercise text or implementation context.
- [Course Overview + Introduction to the Shell](https://missing.csail.mit.edu/2026/course-shell/)
  Primary source for shell fundamentals, command composition, and the first sandbox exercises.
- [Command-line Environment](https://missing.csail.mit.edu/2026/command-line-environment/)
  Primary source for making the shell a productive, programmable working environment.
- [Development Environment and Tools](https://missing.csail.mit.edu/2026/development-environment/)
  Primary source for editors, language tooling, and practical development-environment choices.
- [Debugging and Profiling](https://missing.csail.mit.edu/2026/debugging-profiling/)
  Primary source for systematic debugging and using measurements to understand performance.
- [Version Control and Git](https://missing.csail.mit.edu/2026/version-control/)
  Primary source for Git concepts, history inspection, and advanced version-control workflows.
- [Packaging and Shipping Code](https://missing.csail.mit.edu/2026/shipping-code/)
  Primary source for turning code into a repeatable, shippable artifact.
- [Agentic Coding](https://missing.csail.mit.edu/2026/agentic-coding/)
  Primary source for AI-assisted and agentic development workflows, including their limitations and verification needs.
- [Beyond the Code](https://missing.csail.mit.edu/2026/beyond-code/)
  Primary source for the parts of software work that extend beyond writing source code.
- [Code Quality](https://missing.csail.mit.edu/2026/code-quality/)
  Primary source for testing, automation, review, and maintainability practices.
- [GNU Bash Reference Manual](https://www.gnu.org/software/bash/manual/bash.html)
  Authoritative reference for Bash syntax, expansion, pipelines, functions, and shell behavior.
- [Pro Git](https://git-scm.com/book/en/v2)
  The official Git community book; use it for deeper explanations and command-level reference beyond the lecture.
- [Python Packaging User Guide](https://packaging.python.org/en/latest/)
  Authoritative packaging guidance useful for Django examples and for comparing language-agnostic shipping concepts.
- [.NET diagnostics documentation](https://learn.microsoft.com/en-us/dotnet/core/diagnostics/)
  Official reference for connecting debugging and profiling concepts to the user's .NET work.

## Wisdom (Communities)

- [OSSU community](https://ossu.dev/#community)
