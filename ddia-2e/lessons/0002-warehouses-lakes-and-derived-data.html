DDIA · Ch.1 Trade-Offs in Data Systems Architecture

Warehouses, Lakes and Derived Data

How operational data flows into analytics, and which copy is the truth when they disagree.

Pipelines into analytics

  • ETL (extract–transform–load) moves data into the warehouse, as periodic dumps or a continuous stream. ELT transforms after loading. Generalized, these are data pipelines.
  • Data lake: just files, no imposed format or schema (Parquet, text, images, feature vectors). Cheaper (object storage) and suits data scientists working in Pandas, scikit-learn or Spark rather than SQL. Sushi principle: "raw data is better", so each consumer transforms it their own way.
  • HTAP (hybrid transactional/analytical processing) puts OLTP and analytics in one system, often two engines behind one interface. Useful when one app needs both (e.g. fraud detection), but it doesn't replace the warehouse.
  • Streams let analytics react in seconds (block fraud now). Reverse ETL pushes analytic outputs, such as an ML model, back into operational systems.

Trend: the larger the scale, the more specialized the systems. General-purpose works fine for small data.

Systems of record vs derived data

It's about use, not the tool. The same PostgreSQL can be the system of record in one app and a derived cache in another. Labelling "what's derived from what" clears up a confusing architecture and raises the real question: what process updates the derived data when the source changes?

The search index says a course has 30 seats left; the main database, which every enrollment is written to first, says 28. Which is correct?

When derived data disagrees with the system of record, the system of record is right by definition. Rebuild the index from it.

What is the key difference between a data lake and a data warehouse, and who typically uses each?

A warehouse is a relational database with a cleaned, imposed schema, queried in SQL by analysts. A lake is just files in any format with no imposed schema (Parquet, text, images), cheaper on object storage, used by data scientists with tools like Pandas or Spark ("sushi principle": raw data is better).

Define system of record and derived data, and name three examples of derived data.

System of record: the authoritative source of truth, written first, each fact stored once. Derived data: produced by transforming other data; redundant, and can be rebuilt from the source if lost. Examples: cache, search index, materialized view, warehouse copy, trained ML model.

What are HTAP and reverse ETL, and does HTAP remove the need for a data warehouse?

HTAP runs transactional and analytical workloads in one system (often two engines behind one interface), useful when one app needs both, like fraud detection. Reverse ETL pushes analytical outputs (e.g. an ML model's results) back into operational systems. HTAP does not replace the warehouse, which still integrates data from many sources.
