# .NET Job Preparation Resources

## Knowledge

- [ASP.NET Core middleware — Microsoft Learn](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/middleware?view=aspnetcore-10.0&preserve-view=true)
  Primary source for the ordered request pipeline, request delegates, `Use`, `Run`, `Map`, short-circuiting, and before/after execution. Use for Lesson 1 and later middleware questions.
- [Dependency injection in ASP.NET Core — Microsoft Learn](https://learn.microsoft.com/en-us/aspnet/core/fundamentals/dependency-injection?view=aspnetcore-10.0&preserve-view=true)
  Official explanation of dependencies, the built-in service container, registration, injection, and service lifetimes. Use when the course moves from pipeline structure to application architecture.
- [Tutorial: Create a Minimal API with ASP.NET Core — Microsoft Learn](https://learn.microsoft.com/en-us/aspnet/core/tutorials/min-web-api?view=aspnetcore-10.0&preserve-view=true)
  A current hands-on path for creating a small HTTP API with the .NET CLI and ASP.NET Core. Use once the SDK is available for build-from-scratch practice.

## Wisdom (Communities)

- [ASP.NET Core discussions — GitHub](https://github.com/dotnet/aspnetcore/discussions)
  A maintained project community for real-world questions and edge cases. Use it to compare practical experiences, then verify important claims against Microsoft Learn or source code.

## Gaps

- No target job description has been provided, so the curriculum is intentionally general rather than employer-specific.
- Interview-specific expectations will be refined after the first diagnostic and whenever a real job description becomes available.
- Resources for async/await, testing, Docker/cloud, and system design will be added after the initial pipeline lesson, keeping the reference set focused rather than noisy.
