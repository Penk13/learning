# Mission: .NET Technical Interview Preparation

## Why
I have three years of full-time experience building full-stack applications with C#, .NET Core, and React as part of a team. I want to turn that practical experience into independent understanding so I can explain decisions clearly, build small .NET systems from scratch, and pass general C#/.NET technical interviews.

## Success looks like
- Explain core C# and ASP.NET Core concepts clearly under interview pressure.
- Build and reason about a small .NET Web API without relying on an existing team codebase.
- Discuss async/await, testing, Docker/cloud, and system-design trade-offs with confidence.
- Diagnose gaps through short exercises and improve through spaced mock interviews.

## Constraints
- Lessons should be short: approximately 15–20 minutes.
- Study cadence is flexible: a few sessions per week.
- Teaching language is English.
- The learner already has working professional experience, so lessons should deepen and organize existing knowledge rather than start with beginner syntax.
- The current WSL environment does not have the .NET SDK installed; hands-on build lessons will need an environment setup step first.

## Out of scope
- Becoming an expert in every .NET library or cloud platform.
- Preparing for one employer's private framework or coding-test format before a specific job description is available.
- Cloud certification study as an end in itself.
