Request pipeline (0001)

An ASP.NET Core request pipeline is an ordered sequence of request delegates. Each middleware can do work before and after the next delegate, or stop the request by not calling it.

1 · Middleware A
→
2 · Middleware B
→
3 · Terminal delegate

Forward: A before → B before → terminal. Return: B after → A after.

TermMeaning
MiddlewareHandles part of the request/response journey; may invoke the next component.
Request delegateThe callable that handles an HTTP request at one point in the pipeline.
Short-circuitStopping traversal by not invoking the next delegate.
Terminal middlewareEnds traversal; Run creates a terminal delegate. Use gets a next to call.
  • Registration order on the way in; reverse order on the way out.
  • Code after await next runs while the response unwinds (timing, logging).
  • Order is behavior: exception handling goes early so it can observe later failures.
  • Interview words: ordered, next delegate, before/after, short-circuit.
